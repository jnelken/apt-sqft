# apt-sqft

A tool for analyzing and comparing apartment listings by calculating and visualizing true price-per-square-foot and other normalized metrics. The goal is to cut through the noise in apartment hunting by surfacing the numbers that actually matter — effective cost per sqft, room size ratios, and layout efficiency — across multiple listings at once.

**Current progress:** Dual-structure project (React SPA + Next.js app) with a build pipeline and git hooks configured. Core UI and calculation logic are in progress.

**Final objective:** A web tool where apartment hunters can enter or paste listing details and get a clear, comparable breakdown to make more informed rental decisions.

## Tech Stack

- **Framework:** React + Next.js (dual structure)
- **Language:** TypeScript
- **Linting:** ESLint with git hooks
